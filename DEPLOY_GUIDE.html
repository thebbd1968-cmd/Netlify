Prerequisites

Before starting, make sure you have:

  • GitHub account (your code is at github.com/thebbd1968-cmd/Netlify)
  • Netlify account (free at app.netlify.com)
  • Render account (free at render.com)

Step 1: Deploy the Backend (Render)

Time: ~5 minutes

  1. Go to render.com and sign up / log in
  2. Click Dashboard → New → Blueprint
  3. Connect your GitHub account
  4. Select the repository: thebbd1968-cmd/Netlify
  5. Render will auto-detect the render.yaml configuration
  6. Click Apply
  7. Wait ~2 minutes for the build to complete

Backend URL: https://douglas-re-backend.onrender.com

Step 2: Deploy the Frontend (Netlify)

Time: ~5 minutes

  1. Go to app.netlify.com and sign up / log in
  2. Click Add new site → Import existing project
  3. Connect your GitHub account
  4. Select the repository: thebbd1968-cmd/Netlify
  5. Netlify auto-detects the netlify.toml configuration:
    • Build command: npm run build
    • Publish directory: frontend/dist
  6. Click Deploy site
  7. Wait ~1 minute for the build to complete

Frontend URL: https://[your-site-name].netlify.app

Tip: Customize the URL in Netlify → Site settings → Change site name

Troubleshooting

Frontend shows blank page:
Check that the build succeeded in Netlify deploy log. Ensure _redirects file is in frontend/public/.

API calls fail (502 errors):
Verify your backend is running at the Render URL. Check CORS settings in backend/app/main.py.

Login doesn't work:
Make sure the backend has been seeded with demo data. The backend auto-seeds on first startup.

Alternative: Docker

docker build -t douglas-re-backend .
docker run -p 8000:8000 douglas-re-backend
